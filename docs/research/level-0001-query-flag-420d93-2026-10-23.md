**Method:** GNU objdump 2.45.1-5.fc43 bounded static disassembly; no Ghidra

the nonliteral flag passed at `0x00420d93`. **Confidence:** high for the shown
instructions and stack-argument positions; control-flow feasibility and names

## Observed

The code containing `0x00420d93` begins at `0x00420960` and returns with
`ret 0x1c`, consistent with seven stack arguments on this observed path. At
`0x00420d76`, it tests bit `0x02` in stack argument `[ebp+0x1c]`, loads the
seventh argument from `[ebp+0x20]`, and only takes the dynamic-flag call at
`0x00420d93` when both that bit is set and the seventh argument is nonzero.
Otherwise, the shown alternatives call the same query helper with literal `5`
or pass literal `0x11` to a different helper.

The dynamic flag is therefore not a newly computed value at `0x00420d93`: it
is the nonzero seventh argument of the enclosing `0x00420960` path. The direct
calls found by the bounded whole-image scan show these seventh-argument
provenances:

| Direct call to `0x00420960` | observed seventh argument |
| --- | --- |
| `0x00403989` | literal `0` |
| `0x00420df3` | caller's `[ebp+0x20]` forwarded unchanged |
| `0x004219a8` | literal `0` |
| `0x004219c9` | literal `0` |
| `0x0042868f` | literal `0` |
| `0x0044ca10` | value loaded from that caller's stack `[esp+0x10]` |

Thus the four literal-zero direct entries cannot reach the nonzero dynamic-
flag branch as written. The recursive edge preserves its seventh argument,
and the wrapper edge forwards its fourth argument, so those two edges require
a nonzero incoming value and the bit-`0x02` condition to reach the branch.

Bounded follow-ups establish that neither edge synthesizes a value. The
wrapper at `0x0044c9f0` has one direct relative caller, at `0x0044c940`, which
supplies zero as its fourth argument. The recursive edge only forwards the
enclosing routine's seventh argument unchanged. The new hash-pinned
`verify_level_query_flag_provenance.py` checks the six direct calls to
`0x00420960`, the wrapper's sole direct caller, and 69 instructions covering
all argument pushes for those calls and the relevant stack loads; it rejects
extra pushes, nested calls, or stack-pointer adjustments within the argument
setup spans. It also found no direct unconditional jumps or exact raw address
literals for either target. It uses the exact SHA-verified executable snapshot
for objdump. The anchors also cover the bit-`0x02` and nonzero-value gates
before the dynamic call and the literal-`5` alternative. Twelve synthetic
tests passed, including rejection of bulk and implicit x86 stack changes in
argument setup. These direct edges establish no nonzero
seventh-argument source; indirect or data-driven entries remain outside this
scan. See [the recursive trace](level-0001-query-flag-420df3-2026-10-23.md),
[the wrapper trace](level-0001-query-flag-44ca10-2026-10-23.md), and
[the address-reference check](level-0001-wrapper-address-references-2026-10-23.md).
